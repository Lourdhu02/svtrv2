# Research Workspace

This folder is reserved for paper-first discovery work before implementation.

Suggested subfolders:
- `papers/` for source papers and paper notes
- `datasets/` for benchmark notes, links, and download manifests
- `tools/` for evaluation and training tooling notes
- `gaps/` for research gap analysis
- `modality/` for modality and task framing
- `plan/` for proposed research directions and execution plans

Nothing in this folder is implementation code.
