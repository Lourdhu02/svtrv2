# Agent working notes

Hand-off documents for AI agents (or collaborators) continuing this project.

- **`plan.md`** — the roadmap: phases, tasks, and the exact commands to run each one.
- **`status.md`** — point-in-time snapshot: what is completed (with evidence and commit
  hashes) and what is left, in priority order.

Read `status.md` first to see where things stand, then `plan.md` to pick up the next
task. Keep both updated as work completes — a stale status file is worse than none.
